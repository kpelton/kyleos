03 / INTERACTIONS

Four critical paths

These traces make the high-level arrows concrete. Each step names the owning subsystem or the key function used at the boundary.

File read / write

PATH 01

A userspace descriptor resolves through the current task before VFS dispatches to the mounted implementation.

app→int 0x80→process FD→VFS→FAT / RAMFS / pipe→device
return: byte count or −1 → userspace RAX

Fork then exec

PATH 02

fork shares writable pages as COW; exec replaces the map with validated, lazy file-backed ELF segments.

fork syscall→scheduler→COW VMM→exec syscall→VFS + ELF→new map
fault path: #PF → COW copy or demand-load page → resume

Timer preemption

PATH 03

The PIT supplies 100 ticks per second. Every second tick reaches the round-robin scheduler for a 50 Hz scheduling cadence.

PIT IRQ0→IDT 32→timer_irq→jiffies++→schedule→context switch
state: RUNNING → READY; sleeping timers may become READY

waitpid + WNOHANG

PATH 04

WNOHANG selects a locked, non-blocking child scan instead of putting the parent on its wait channel.

waitpid→syscall 7→process_wait→sched_reap_child→PID / 0 / −1
0 = matching child still runs; PID = reaped; −1 = no match
